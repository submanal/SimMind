# Симуляция эволюции животных

Животные ищут еду, тратят энергию и размножаются. Потомки наследуют гены с возможными мутациями. Симуляция позволяет сравнивать, какие признаки и стратегии помогают дольше жить и оставлять больше потомства.

**Стек:** C++ для симуляции мира, Python для поведения и обучения животных, Matplotlib для визуализации и сравнения результатов.
